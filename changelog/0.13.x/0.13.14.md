# 0.13.14 — 2026-10-08

## Added

- **Three more representation repairs** ([#707](https://github.com/cyanheads/mcp-ts-core/issues/707), [#602](https://github.com/cyanheads/mcp-ts-core/issues/602), [#616](https://github.com/cyanheads/mcp-ts-core/issues/616)): a string spelling a number or boolean (`"15"` → `15`), a lone string for an array (`"yell"` → `["yell"]`, never one holding a comma or line break), and `null` at an optional key, which is deleted. `mcp.input.coercion` gains `string_as_number`, `string_as_boolean`, `string_as_array`, `null_as_absent`; `coerce: false` turns them off.

## Changed

- **Repairs reach a union field's one surviving branch** ([#570](https://github.com/cyanheads/mcp-ts-core/issues/570)), **a discriminator or literal tag no variant takes** ([#714](https://github.com/cyanheads/mcp-ts-core/issues/714)), and **what a `z.preprocess()` or `.transform().pipe()` made of the value** ([#599](https://github.com/cyanheads/mcp-ts-core/issues/599)): `[123, "a"]` against `string | string[]` reaches the handler as `["123", "a"]`, `{ kind: "1" }` against tags `1` and `2` as `{ kind: 1 }`. A call 0.13.13 repaired keeps its value.
- **A rejection reports only the repairs that held** ([#706](https://github.com/cyanheads/mcp-ts-core/issues/706)): fourteen integer PMIDs against `.max(10)` report the `too_big` alone, not fourteen `Send pmids.N as a string` sentences. A call no repair helped gets its `coerce: false` rejection.
- **An alias sent beside its target is named as one** ([#639](https://github.com/cyanheads/mcp-ts-core/issues/639)): `maxResults is an alias of pageSize; send one of them, not both.` replaces the unknown-key or dropped-key sentence. The message, `data.issues`, and `data.input` are unchanged.
- **A union whose branches all failed on one literal tag renders that literal once**, at its full path, naming every branch's value (`target.kind: Invalid option: expected one of "a"|"b"`).
- **The `-32602` result is cut at 10 issue lines** in the message and hint (each at most 1,024 characters, then ` (+N more)`), 10 entries per array and keys per object, 1,024 characters per string and key, and two levels of lists and objects below each issue in `data.issues` and `data.input`, and 30 issues in all through union branches. `issuesCount`, `errorsCount`, and `<key>Count` / `<key>Length` / `<key>KeyLength` / `<key>Lengths` record each cut, never under a kept key's name.
- **Skills** — `add-tool` 2.34, `api-errors` 1.22, `api-telemetry` 1.20, `api-testing` 1.15, `design-mcp-server` 2.32 (a `.max()` earns its place; an output-only ceiling takes none; a write batch over its cap rejects before doing anything), `field-test` 2.21 (probe one past a bound).

## Fixed

- **Prompt arguments are parsed once, by the SDK** ([#643](https://github.com/cyanheads/mcp-ts-core/issues/643)): `z.stringbool()` and type-changing `.transform()` arguments no longer reject every call, an async refinement no longer fails with `-32603`, and a transform runs once, so `s => s + '!'` hands `generate` `hi!`, not `hi!!`.
- **A rejection under a `z.preprocess()` or `.transform().pipe()` no longer says `Provide` or `Missing required field` for a value the caller sent** ([#599](https://github.com/cyanheads/mcp-ts-core/issues/599)): a lone object a preprocess wraps as a list renders as its list form, and a wrong type at the transform restates its issue line instead of `Send … as …`.
- **The integration lane's build-freshness check compares only the files the TypeScript build reads**, so a stray dotfile no longer marks `dist/` stale.

## Security

- **A tool-argument rejection's size and CPU are bounded** whatever the caller sends, recursive union schemas and caller data a custom issue carries included ([#648](https://github.com/cyanheads/mcp-ts-core/issues/648)). The cut and the 30-issue budget bound the size; the rejection's readers and schema walks each read a shared issue or union once, which bounds the CPU.
- **The repair's container writes are linear in a request's issue count**: each container on the repaired paths is copied once, however many values it repairs.
