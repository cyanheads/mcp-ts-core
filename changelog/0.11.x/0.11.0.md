# 0.11.0 — 2026-07-26

## Changed

- **`peerDependencies` floors raised** — every optional peer moves to the version this release resolves. A consuming server that installs an affected peer must raise its own range or the install reports an unmet peer; arrows under Dependencies. Peers a server doesn't install are unaffected.
- **TypeScript 7** — `typescript` ^6.0.3 → ^7.0.2 drives `typecheck`, `typecheck:scripts`, and the build. `templates/package.json` scaffolds new servers on it.
- **`scripts/audit-open-index-signatures.ts` keeps the TypeScript 6 parser** through a `typescript-v6` alias (`npm:typescript@^6.0.3`). TypeScript 7 dropped the programmatic compiler API — the replacement behind `typescript/unstable/*` has no standalone parser and is slated to change again in 7.1. The audit is a pure syntactic walk, so it holds the stable v6 parser while `tsc` runs on 7.
- **`check-dependency-specifiers` scans `overrides`** under the strict rule: `latest`, `*`, and dist-tags all fail there, unlike `peerDependencies` / `optionalDependencies`, which may legitimately float. An override holds a transitive at a specific version, so a floating specifier re-resolves the pin the entry exists to enforce while the block still reads as present. Non-string values — the npm nested-override form — are skipped rather than throwing.
- **`docs:generate` is non-functional.** typedoc 0.28.20 peers on TypeScript 5.0–6.0 and imports the compiler API TypeScript 7 removed, so `bunx typedoc` throws on load. No typedoc release supports TypeScript 7 yet; the script stays in place pending one.
