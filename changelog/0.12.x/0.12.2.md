# 0.12.2 — 2026-08-20

The Phase 2 remainder of the SDK v2 migration ([#305](https://github.com/cyanheads/mcp-ts-core/issues/305)).

## Added

- **`createApp({ cacheHints })`** ([#359](https://github.com/cyanheads/mcp-ts-core/issues/359)) sets `ttlMs` / `cacheScope` per cacheable operation — `tools/list`, `prompts/list`, `resources/list`, `resources/templates/list`, `resources/read`, `server/discover`. An invalid `ttlMs` fails at startup with a `ConfigurationError` naming the field rather than an SDK `RangeError`.
- **`cacheHint` on a resource definition** ([#359](https://github.com/cyanheads/mcp-ts-core/issues/359)) overrides the `resources/read` entry for that one resource, field by field; both unset keeps the SDK defaults (`ttlMs: 0`, `cacheScope: 'private'`). 2025-era responses are unaffected either way. `CacheHints`, `CacheableResultMethod`, `CacheHint`, and `CacheScope` export from the package root.
- **`headerParam(schema, 'Name')`** ([#360](https://github.com/cyanheads/mcp-ts-core/issues/360)) designates a tool input property with `x-mcp-header`, so its value also rides an `Mcp-Param-Name` request header and an intermediary can read it without parsing the body. It mirrors rather than relocates — the handler still reads the argument from `input`, and description, type, and requiredness are unchanged.
- **`header-param-designation`** (error) flags a designation that is not a non-empty RFC 9110 token, not case-insensitively unique across the schema, not primitive-typed, or not statically reachable through a chain of `properties` keys — an array element, a `z.record()` value, and every field of a discriminated-union input root are all unreachable. `tool()` throws on the same condition at definition time.

## Changed

- **`ManifestTransport['sessionMode']` narrows from `string` to `'stateful' | 'stateless'`** ([#357](https://github.com/cyanheads/mcp-ts-core/issues/357)). The `auto` resolution lives in one exported `resolveSessionMode`, read by the HTTP transport's session store, the handler factories' `ctx.sessionId` gate, and the manifest alike.
- Shipped skills: `add-resource` 1.5, `add-tool` 2.20, `api-config` 1.12, `api-linter` 1.12.

## Fixed

- **`transport.sessionMode` reports the mode the server actually runs in, never `auto`** ([#357](https://github.com/cyanheads/mcp-ts-core/issues/357)). A default HTTP deployment serves sessions statefully while advertising `auto` on the landing page and the `/.well-known/mcp.json` server card; it reads `stateful` there now.

## Dependencies

- `openai` `^7.4.0` → `^7.5.0` (dev) — a minor inside the existing `^6.48.0 || ^7.0.0` optional peer range.
